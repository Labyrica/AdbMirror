HOW IT WORKS
Three components, one stdio pipe
Claude Code launches the MCP server automatically. It communicates via JSON-RPC over stdin/stdout — the same protocol used by all MCP tools.

18 TOOLS
Everything Claude needs to work with your device
Each tool appears natively in Claude Code — no Bash commands, no curl wrappers.
screenshot
Capture the device screen and return as a PNG image that Claude can see and analyze.
VISION
tap
Find UI elements by text, content description, or resource ID and tap them. Supports long press and double tap.
INTERACTION
crash_log
Extract FATAL EXCEPTION, ANR, and native crash traces with parsed stack traces and timestamps.
DIAGNOSTICS
ui_tree
Get the full UI hierarchy with text, bounds, clickable state, and resource IDs for every element on screen.
VISION
app_logs
Filtered logcat output by package, log level, time window, and regex pattern. Up to 200 lines.
DIAGNOSTICS
swipe
Swipe by exact coordinates or simply say "up", "down", "left", "right" from screen center.
INTERACTION
input_text
Type text into the focused field. Auto-escapes special characters for ADB compatibility.
INTERACTION
press_key
Press device keys: back, home, enter, menu, volume, power, tab, delete, escape.
INTERACTION
app_status
Check if an app is running, foreground or background, its PID, and memory usage.
DIAGNOSTICS
device_info
Model, manufacturer, Android version, screen resolution, density, battery level, storage.
MANAGEMENT
install_apk
Install APK files with auto-granted runtime permissions. Replace existing installs.
MANAGEMENT
performance_snapshot
FPS, janky frames percentage, total/native/Java heap memory breakdown.
DIAGNOSTICS
pixel_color
Sample pixel color at any coordinate. Returns hex, RGB, luminance, and dark/light classification.
VISION
launch_app
Launch any app by package name. No need to know the activity — uses the app launcher.
MANAGEMENT
shell
Run any ADB shell command for advanced operations not covered by the other tools.
MANAGEMENT
screen_record
Record the device screen to MP4. Up to 180 seconds. Saved to a local file path.
VISION
list_packages
List installed packages filtered by name. Show third-party only or all apps.
MANAGEMENT
force_stop
Force stop a running app by package name. Useful for restart-and-test cycles.

GET STARTED
Three steps to AI-powered Android debugging
Works with any Claude Code project. No SDK changes required.
1

Download

Grab the single-file binary for your platform. No dependencies needed — the .NET runtime is bundled.

adb-bridge-win-x64.exe adb-bridge-osx-arm64 adb-bridge-linux-x64
2

Configure

Add one block to your Claude Code settings. Or click the copy button in the PhoneMirror app.

{ "mcpServers": { "adb-bridge": { "command": "path/to/adb-bridge" } } }
3

Ask Claude

The tools appear automatically. Just describe what you want — Claude handles the ADB commands.

$ claude you: Take a screenshot and check for crashes claude: Using screenshot... Using crash_log... Done.
